Crear un token para TopeRC
  1. Abre GitHub con tu cuenta dgarana.
  2. Selecciona el propietario toperc y Only select repositories → toperc.github.io.
  3. Comprueba el permiso Contents: Read and write y la caducidad de 7 días para esta prueba.
  4. Genera el token, cópialo y pégalo en el campo de arriba. No lo compartas en el chat.
